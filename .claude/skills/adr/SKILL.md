# ADR 저작

> **이것은 잠정판(관측 장비)이다.** 목적은 편의가 아니라 **마찰을 드러내는 것**이다.
> **묻는다, 채우지 않는다** — 답할 수 없는 인자가 곧 우리가 안 정한 것이다. 조용한 기본값으로 미결을 덮지 않는다.
> 이 skill을 고쳤다면 **고친 이유를 마찰 로그에 남긴다.**

기계가 하는 일과 사람·agent가 판단하는 일은 갈라져 있다. 아래에서 **판단**이라고 적힌 것은 스크립트가 대신하지 않는다.

## 0. 먼저 판단한다 — 이게 ADR감인가

스크립트를 부르기 전에 답한다. 답이 안 나오면 **문서를 만들지 않는다.**

- **임계선(§4②)** — one-way door인가? `되돌리기 어려움 × 영향 범위`. **되돌리는 데 한 시간이면 ADR이 아니다** → 티켓·코드로 보낸다.
- **입도(§4③)** — *"결정 X가 뒤집힐 때 Y도 반드시 함께 무효가 되는가?"* **예** → 한 ADR. **아니오** → 별개 ADR.
- **"왜"만(§4①)** — 수치·리소스명·필드값이 본문에 들어가려 하면 그것은 코드의 관할이다.

이 셋은 **기계화할 수 없다.** 체크리스트로 제시만 하고, 판정은 사람·agent가 한다.

## 1. 인자를 묻는다

| 인자 | 어떻게 |
|---|---|
| `topic` | **묻는다.** 폴더 이름이 된다(`docs/{topic}/adr/`). 기존 topic 목록: `ls docs/` |
| `subjects` | **★ 기존 목록을 보여주고 묻는다** — `scripts/list-subjects.py` 실행 후 그 결과를 제시한다 |
| `parent` | **묻는다.** 이 결정이 딛고 선 **직상위 축**의 ADR id. 없으면 비운다 — **깊이 제한은 없다** |
| `references` | **묻는다.** parent가 아니나 이 결정을 온전히 이해하는 데 필요한 다른 결정들의 id(여럿 가능). 없으면 비운다(§7 · ADR-0004) |
| 슬러그 | **묻는다.** 파일명이 된다 — 소문자 kebab-case, 3~6 단어 |
| `id` | **자동** — `scripts/next-id.py` (순수 기계) |
| `accepted_at` | **자동** — accept 할 때 `scripts/accept.py` 가 채운다. **손으로 적지 않는다** |
| "무효화 조건" | **묻는다. 못 채우면 비운 채로 둔다** — 억지로 지어내지 않는다. 채택 여부는 실측으로 판정한다 |

```bash
.claude/skills/adr/scripts/list-subjects.py     # 기존 subjects 어휘 + 인덱스 드리프트 경고
.claude/skills/adr/scripts/next-id.py           # 전역 순차 ADR 번호 (충돌 감지)
```

**`subjects`는 구체 명사만**(§7). 판별: ***"이것이 시스템에 실제로 존재하는가?"*** `architecture`·`performance` 같은 **범주는 subject가 아니다.**

**문서가 0건이면 어휘 목록은 빈 배열이다.** 이것은 에러가 아니라 **정상 경로**다 — *"기존 subject 없음. 새로 정의합니다"* 라고 말하고 진행한다. 첫 문서의 `subjects`가 **어휘의 씨앗**이 되므로 특히 신중히 고른다.

## 2. 쓴다

경로는 스크립트가 도출한다 — 슬러그를 여기서 검증한다:

```bash
.claude/skills/adr/scripts/doc-path.py --topic <t> --id ADR-0001 --slug <slug>
# → docs/{topic}/adr/adr-0001-<slug>.md
```

파일명은 **소문자**이고 **id가 선두**다(§7) — 인용키로 바로 찾기 위해서다. frontmatter의 `id`는 대문자(`ADR-0001`), 파일명은 소문자(`adr-0001-…`)다.
**타입 폴더는 lazy 생성**(§7) — 이 ADR이 그 topic의 첫 ADR이면 여기서 `adr/`가 처음 생긴다.

> ⚠ **이름은 accept 시 얼어붙는다** — 그 뒤로 rename은 금지다(경로를 갈면 인용이 깨진다). 슬러그를 지금 제대로 고른다.

```yaml
---
id: ADR-0001
type: adr
topic: ops-workflow
subjects: [a, b]
status: proposed
accepted_at:       # 비운다. accept.py 가 채운다 — 손으로 적지 않는다
parent:            # 직상위 축의 ADR id. 루트면 지운다
references:        # parent 아닌 필요 맥락의 id(여럿 가능). 없으면 빈 채로 둔다
superseded_by:
---

# ADR-0001 — <결정 한 문장>

## Context
<왜 지금 이 결정이 필요한가. 제약. **자족적으로** 쓴다 — 이 저장소 밖 문서에 기대지 않는다>

## Decision
<무엇을 정했나. "왜"만. 파라미터·구현은 코드의 관할>

## Alternatives
<검토했고 버린 선택지 — 버린 이유와 함께. 여기가 이 문서의 값이다>

## Consequences
<받아들이기로 한 대가>

## 무효화 조건
<이 결정이 무효가 되는 조건. **채울 수 없으면 비워 둔다** — 지어내지 않는다>
```

**자족성** — 이 저장소 밖 문서를 링크·인용하지 않는다. 외부 결정표의 번호(`D12` 같은)를 쓰지 않는다. 읽는 사람이 이 파일만으로 결정을 이해할 수 있어야 한다.

**경계는 필요할 때만 명시한다.** *"X는 여기서 정하지 않는다 · 별도 결정이다"* 를 반사적으로 적지 않는다. 이 문장은 **모호한 침묵을 명시적 배제로 바꾸는** 값이 있을 때만 둔다 — X가 **① 헷갈릴 만큼 인접하고 ② 실재하는(또는 곧 생길) 결정 영역**일 때. 그 외에는 노이즈다 — *이 문서가 안 정하는 것*은 무한하다.

- **한 문서에 같은 경계를 두 번 적지 않는다.**
- **양성 서술이 문을 닫게 둔다** — Decision이 또렷하면 배제는 저절로 추론된다. 명시는 그걸로 안 닫힐 때만.
- 기계가 읽는 공동무효 경계는 `parent`·`references`에 산다 — 산문 배제는 **사람이 걸려 넘어질 지점**에만 둔다.

## 3. accept — 동결선을 넘는다

`proposed` → 셀프 리뷰 → **스크립트가 넘긴다.** 손으로 `status:` 줄을 고치지 않는다.

```bash
.claude/skills/adr/scripts/accept.py ADR-0001
```

이 스크립트는 `status`와 `accepted_at`을 함께 기록하고, **파일명이 규약에 맞는지 마지막으로 검사**한다 — 이름이 잘못된 채 얼면 되돌릴 방법이 없기 때문이다(rename 금지).

**여기서부터 본문도, 경로도 동결된다**(§3). 이후 허용되는 편집은 딱 둘: **`status`** · **`superseded_by`**. 유예 기간은 없다.

> **`accepted_at`은 권위 있다** (§7 · ADR-0004) — *"검토가 언제 끝났는가"* 에 **문서가 스스로 답한다.** 그래서 **사람이 손으로 적지 않는다**: 틀리면 문서가 거짓말을 하고, **대조할 바깥이 없다.**
>
> **동결 시각이 아니다.** *검토가 끝난 것*(문서의 사실, **시각**)과 *되돌릴 수 없게 된 것*(공표, 저장소의 사실, **상태**)은 다른 사실이다. **accept 한 날과 커밋한 날이 어긋나는 것은 정상이다** — 도구는 둘을 대조하지 않는다.

## 4. 동결된 문서를 건드리려 할 때

**본문을 고치기 전에 반드시 먼저 돌린다:**

```bash
.claude/skills/adr/scripts/freeze-check.py <path>   # accepted/superseded/frozen → exit 1
.claude/skills/adr/scripts/freeze-check.py          # 동결 문서 전량의 경로 변경을 훑는다
```

**동결은 경로에도 걸린다.** 본문을 얼려 놓고 파일을 옮기면 그 ADR을 가리키던 인용이 전부 깨진다 — 얼린 의미가 없다. 인자 없이 돌리면 HEAD와 대조해 **옮겨진 동결 문서**를 찾아낸다.

**exit 1은 우회하지 않는다.** 결정을 바꾸려면 **새 ADR로 supersede**한다 — 옛 ADR을 고치지 않는다.

**부분 supersede는 없다.** 옛 ADR 전체가 `superseded`가 되고, 여전히 유효한 부분은 **새 ADR에 재진술**한다.

```bash
.claude/skills/adr/scripts/supersede.py --old ADR-0001 --by ADR-0007
```

이 스크립트는 **frontmatter의 두 필드만** 건드린다 — 본문에 손댈 방법이 없다. 그것이 R4를 규율이 아니라 구조로 만든다.

## 5. 쓴 다음

`docs/`는 **지식 플레인**이다 — **커밋은 사람이 승인한다**(§6). agent가 무인으로 밀어 넣지 않는다.

문서를 추가·변경했으면 인덱스를 다시 만든다 → **`docs-index` skill**.
